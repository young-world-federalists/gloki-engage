## Why these lanes (the headline findings)

From the audit (full list in `MASTER_TODO.md` §11):

- **9 dialogs hand-roll modals + buttons + banners** instead of using the shared kit. Blocks Ouri
  from reviewing dialog logic separately from chrome. → addressed by #3.
- **Liquid delegation (D3)** — the third transferable DAO mechanism — is still missing. → built in #4
  on top of extracted VotingFlow primitives.
- **Token violations everywhere:** hardcoded pink hexes for logout, `rgba(0,0,0,0.5)` backdrops,
  locally-redefined `$initiative/$collab/$chat` colors across 6+ files. → #1 enforces tokens.
- **Modal lacks aria-labelledby + focus trap** — WCAG blocker every dialog inherits. → #3 fixes it
  once.
- **5+ copies of `formatTime`, 2 copies of `buildTree`, 3 copies of `initials`** — silent maintenance
  taxes. → #2 sweeps them into `src/utils/`.
- **Country flags rendered 3 different ways** — breaks the transnational-collaboration principle by
  making cross-border cues inconsistent. → #2 + #3 canonicalize via `<CountryFlag>`.
- **Mega-components** (ProblemStage 512 lines, AdoptionFramework 359, DeliberationThread 385) bundle
  orchestration + helpers + state. → #4 splits ProblemStage; #2 extracts the helpers.
- **i18n fragmented**: en/fr/sw out of parity (70 lines each vs many inline defaults); Nairobi and
  Lilongwe users see English placeholders. → #5 fixes the imbalance.
- **MandatePage mixes real `getInitiative` call with demo fixtures** — contradicts the UI-only
  contract. → quick win, applied in a Foundation batch-2 pass.
